# CitySeek 本地部署实现计划

目标：在本地单实例部署下修复缓存与订单正确性，补充 Spring Task 扫描和 Caffeine，使用真实 Redis 与独立测试数据库验证。

范围：保留 Java 8 兼容源码；允许使用已安装 JDK 17 构建。保留 RocketMQ，另提供 local 配置以本地后台任务替代消息传输，数据库业务处理复用。跳过真实支付、真实退款、集群、全量 Outbox 和分布式调度；明确 Redis 丢失不能自动恢复全部预占。

取消后允许重新抢购。库存释放通过用户对应订单号校验，旧订单不能释放新预占。支付仅模拟且要求当前登录用户拥有订单。

- [x] 1. 基线构建，隔离旧的人工数据准备测试；使用独立临时 Redis 与 H2 测试，不影响本机已有数据。
- [x] 2. 用缓存缺失／过期／负缓存测试复现错误，修正锁持有者释放、回源与物理 TTL；加入 Caffeine 展示缓存。
- [x] 3. Lua 原子预占同时记录待落单任务，移除遗留 Stream；失败投递由后台重试，重用同一订单号。
- [x] 4. 数据库事务内完成幂等落单和条件扣库存；回归重复消息、库存不足回滚。
- [x] 5. 统一支付／关单条件更新；Spring Task 扫描到期订单、重试 Redis 幂等释放；延迟消息重复或提前到达不提前关单。
- [x] 6. 缓存更新在提交后失效，失败保留数据库补偿任务，限流用唯一请求标识。
- [x] 7. local 配置、独立建库脚本、本地模拟支付与订单状态查询；补充 README，删除未经验证性能声明。
- [x] 8. 单元／集成验证，启动 local 实例执行抢购、取消重抢、模拟支付、缓存更新冒烟；记录实际结果，提交改动。

验证方式：先运行新增行为测试看到失败，再实现；数据库用 H2 MySQL 模式测试事务，Redis 在随机独立端口启动真实实例。最终本地 MySQL 冒烟使用新数据库，不覆盖已有库。RocketMQ 外部服务不可用时明确不声称验证 Broker 投递。
